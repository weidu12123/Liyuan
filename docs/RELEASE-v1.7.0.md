# Liyuan Agent 1.7.0

## 新增与改进

- 角色卡前端页面与动态脚本全面兼容
    - 完整支持复杂角色卡的动态界面、自定义交互脚本、按钮事件、弹窗提示与消息楼层变量联动，各角色卡脚本在安全沙箱内独立运行、互不干扰
    - 支持角色卡与世界书中的动态条件模板与变量运算，可随剧情章节与状态自动切换生效设定，减少无效设定占用的上下文
- 中转防拦截与自愈保护（位于「提示词 → 预设库 → 中转设置」，不依赖预设、全模式独立生效）
    - 提供「工具交稿」「输入搬运」「防路由护盾（含强混淆）」与「兼容网关附带 Gemini 安全放行」选项，应对中转网关对输入内容的敏感词审查与路由特征识别
    - 遇到上游输入拦截或静默拒答时，自动在本次请求内逐级切换保护策略重发，尽量保证正常出稿不中断
- 预设装载细节优化
    - 支持在装载预设时自动求值其中的条件模板片段，更准确保留创作与排版规则；内置「优先用稿纸工具交稿」条目，支持独立开关

## 修复

- 修复部分大型角色卡正则替换（含宏变量展开）与异步刷新在前端页面中不生效的问题
- 修复跨世界线分支或切换角色卡时，界面变量与正则表达式状态残留的问题
