# Liyuan Agent 1.6.7

## 新增与改进

- 生成中断保留正文与自动从断点续写
    生成途中遇到敏感词拦截（`content_filter`）或网络波动中断时，不再清空已经生成的文字；自动重试改为从截断处继续往下写并无缝拼接，彻底解决写到一半报错导致内容全丢的问题
- 扮演模式旁路助手体验升级
    - 支持为助手单独指定模型（可在「角色 → 助手」或「连接」面板设置，未指定时默认跟随主模型）
    - 助手对话卡片支持单轮重试、修改提问重发、回退到此轮之前、以及删除单轮对话
    - 助手性格设定模板支持自由新增、删除与一键恢复默认模板
- 项目资产升级为完整项目工作空间
    - 「项目资产」面板支持查看与编辑模型在当前项目下创建的全部文件与子文件夹
    - 模型在当前项目空间内读写文件或运行命令无需反复弹窗确认，且严禁越界修改外部文件
    - 恢复世界书创建、写入与修改能力，使用写卡工具保存角色卡内嵌世界书时自动同步挂载

## 修复

- 修复「Agent 预览」小窗无法鼠标拖拽移动与缩放的问题
- 修复中转站中文报错或非标准中断原因无法触发自动重试的问题
