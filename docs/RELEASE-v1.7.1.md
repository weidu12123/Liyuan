# Liyuan Agent 1.7.1

## 新增与改进

- 英文全链路体验补全
    - 界面切换为英文后，斜杠命令提示、过程条、状态栏与登场名录、报错提示、桌面端菜单以及内置系统提示词和工具交互均同步切换为英文；未手改过的内置提示词会随语言自动无损切换，中文模式体验保持原样
- 新增 Turbo 模式（完全开放权限）
    - 位于「设置 → agent 行为」，开启前需二次确认；开启后完全放开跨目录文件读写、终端命令执行询问与世界书/记忆写入限制，适合在个人设备上追求无打断自动操作时使用
- 模型默认开启原生看图能力
    - 连接配置中未单独指定输入能力的模型，默认即可直接识图，无需手动编辑配置文件补写图片能力
- 状态栏与登场名录实用管理
    - 状态栏顶部新增「手动更新」按钮，点击即可基于最新一轮剧情立即补跑一次状态刷新
    - 登场名录各分节新增「清理非活跃」一键按钮与单条「合并」功能，方便快速整理重复或过期的角色、地点与事件条目

## 修复

- 修复引擎强行干预叙事语言的问题，移除内置语言强制要求与自动纠偏，正文与前情摘要统一顺应当前对话、角色卡与预设本身的语言
- 修复部分角色卡加载提示词模板脚本时误报「提示词模板未安装」的问题，并支持相关模板设置跨刷新保存
- 修复状态栏条目较多时无法上下滑动（桌面端与手机端），以及长对话下状态栏偶发卡住停更的问题
- 修复后台状态更新与前情摘要被固定回复长度上限截断的问题，现已改为遵循连接配置中对应模型自身设置的「最大回复」上限，并在更新失败时于界面给出可见提示
- 修复扮演模式下长对话上下文接近上限时不触发自动压缩、导入会话不计入压缩拍数、底部消息数混入重 roll 分支、以及压缩后「项目资产 → 前情提要」需手动刷新才显示的问题
- 修复场景切换后仍在场的角色被误标为「已离场」，以及地点名录随对话不断堆积的问题
- 修复手机端底部导航栏遮挡页面最底下一行内容的问题（如预设库、状态栏等底部条目被挡住无法点击）
