# Liyuan Agent 1.6.6

## 新增与改进

- 全新扮演模式旁路助手（`/btw` · `@助手`）
    移除旧版副编剧弹窗，改为对话流内联助手卡片；支持跨回合持久记忆、历史轮次自动折叠，可在「角色 → 助手」自定义名称、头像与性格设定
- 大幅提升新建对话与切换对话的流畅度
    消除切换项目或对话时需要等待数秒才刷新页面的卡顿问题
- 项目资产彻底隔离
    旧版卡级记忆与补充设定集全面收口至单局「项目资产」，同一角色卡下新开对话不再混入旧档的剧情记忆或设定大纲
- 模型请求失败自动重试（最多 5 次）
- 自定义面板支持自由拖拽移动与缩放（PR #15）

## 修复

- 修复自定义面板在部分场景下显示空白的问题（PR #15）
- 修复同一模型配置多条思考档位时参数被覆盖的问题（PR #16）
- 修复复杂角色卡前端多 `<script>` 脚本报错及 JSON 格式 `[InitVar]` 变量初始化失败的问题
